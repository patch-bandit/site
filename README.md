# Patch Bandit

The source for [patchbandit.com](https://patchbandit.com): free online tools and CSS experiments from a raccoon who'd rather you didn't pay rent on simple software.

## Run it

```sh
npm ci
npm run build
npx astro preview
```

The built site lands in `dist/`. Pushing to `main` builds and publishes it on Cloudflare Pages.
